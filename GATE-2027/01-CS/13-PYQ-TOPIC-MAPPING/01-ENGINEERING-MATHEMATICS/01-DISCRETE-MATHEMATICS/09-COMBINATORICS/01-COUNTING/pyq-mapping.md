## Notes

- **2024 CS1 Q.34.** Asks for the number of spanning trees of the complete graph on 4 labelled vertices.
- **2022 — Q.37.** Number of 3-cycles expressed using the trace of a power of the adjacency matrix.
- **2019 Set-2 Q.5.** Computer Science section. The options are the older single-choice form: only I, only II, both, or neither.
- **2019 Set-2 Q.12.** Number of distinct Hamiltonian cycles in the complete graph on n vertices.
- **2011 Booklet A Q.29.** Number of ways to place a given set of keys so that a drawn tree is a binary search tree.
- **2007 — Q.85.** Linked to Q.84, with one grid segment forbidden.
