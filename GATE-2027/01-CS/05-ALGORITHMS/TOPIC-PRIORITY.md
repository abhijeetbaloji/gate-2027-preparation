## Why P1, P2, and P3 are not filled in

P1, P2, and P3 in the Engineering Mathematics index are bands on mapped row counts. The same bands cannot be computed here. A rank based only on how large a topic feels would ignore the instruction to use the mapping.

When `pyq-mapping.md` files are added, replace each count with the number of rows, set recent presence to the latest mapped year, set years covered from the mapped years, and only then assign:

- P1 — high priority, from a high mapped count and recent papers
- P2 — medium priority
- P3 — lower priority

Until those rows exist, study every syllabus line. The 100-day plan already sequences them: searching, sorting, and hashing on day 44; asymptotics and divide-and-conquer on day 45; greedy on day 46; dynamic programming on day 47; graph traversals and minimum spanning trees on day 50; shortest paths on day 51. That sequence is a calendar in `../00-100-DAY-PLAN/`. It is not a frequency ranking and it is not a prediction.
