## Missing or ambiguous mappings

The entire Algorithms section is unmapped. That is a missing mapping, not a claim that no Algorithms question was set.

The Engineering Mathematics README mentions a few questions only to explain why they were left out of Engineering Mathematics. Those mentions are not complete, and they are not classified with marks and type under an Algorithms topic. They are recorded here so they are not mistaken for this section’s index:

- Huffman coding and matrix-chain multiplication are named as algorithm questions, without a year or question number in that file.
- Towers of Hanoi execution time is identified as 2012 Q.16, as a recurrence stated as a running time, and Master-theorem questions tied to running time are mentioned as a class.
- Minimum spanning trees, shortest paths, and graph traversals are named as a class. The same paragraph cites 2021 CS Set-1 Q.16 and Q.36. In that file, Q.16 is a count of edges in a connected planar graph and Q.36 is a diameter defined using shortest paths. Neither citation is a full Algorithms mapping row.

2017 Session 1 is missing from `12-PYQ` because the official file is not a readable PDF. Those questions were not reconstructed.

Do not fill `PYQ.md` from this list. Add a row only when a `pyq-mapping.md` file states the year, question, type, and source.
