## 1. What a regular language is

A language `L ⊆ Σ*` is **regular** if any one of the following holds. They are equivalent (Kleene).

| Description | Why it is the same family |
|---|---|
| `L = L(r)` for a regular expression `r` | Kleene |
| `L` is accepted by some DFA | subset construction, state elimination |
| `L` is accepted by some NFA / ε-NFA | |
| `L` is generated by a right-linear grammar | Section 7 |
| `L` is generated by a left-linear grammar | Section 7 |
| The Myhill–Nerode relation of `L` has finite index | Section 8 |

So “give a DFA”, “give an RE”, and “the distinguishable prefixes are finite in number” are three ways to **prove regularity**. The pumping lemma is not on this list: it is only a necessary condition, and it never proves that a language is regular ([pumping lemma](../07-PUMPING-LEMMA/)).

Every finite language is regular: build a trie DFA along the accepted strings and send every illegal continuation into a rejecting sink. In particular `{ε}` and `∅` are regular.

Every regular language is a context-free language: a DFA is a PDA that ignores the stack, and a right-linear grammar is a CFG. The converse is false (`{a^n b^n}`).

## 2. Closure table, with the construction

Assume `L` and `M` are regular, with DFAs `A` and `B`.

| Operation | Closed? | Why |
|---|---|---|
| Union `L ∪ M` | yes | NFA: new start, ε-edges into both starts. Or product DFA, accept if either component accepts |
| Concatenation `LM` | yes | NFA: ε-edges from accepts of `A` to the start of `B` |
| Star `L*` | yes | NFA: new start (accepting), ε to old start, ε from old accepts back to old start |
| Complement `Σ* − L` | yes | Complete the DFA, swap accept and non-accept. Completeness matters: a missing transition would become an accidental accept after the swap |
| Intersection `L ∩ M` | yes | Product DFA, accept if **both** components accept. Equivalently `L ∩ M = Σ* − (L̄ ∪ M̄)` |
| Difference `L − M` | yes | `L ∩ M̄` |
| Reverse `L^R` | yes | Reverse every edge of an NFA; old accepts become sources from a new start (ε-edges if several); old start becomes the unique accept |
| Homomorphism `h(L)` | yes | Replace each `a`-edge by a path that spells `h(a)` (an ε-edge if `h(a) = ε`) |
| Inverse homomorphism `h^{-1}(L)` | yes | From a DFA for `L`, put an `a`-edge `p → q` exactly when `h(a)` takes `p` to `q` |
| Prefix / suffix / right quotient | yes | Section 6 |

**Why complement needs a DFA, not an NFA.** Flipping the accept set of an NFA does not complement the language: a string that had *some* accepting path and *some* rejecting path would be rejected after the flip, but it was in the original language. Convert to a DFA first (or use the product with a complete DFA).

**Why reverse is easy on an NFA and awkward on a DFA.** Reversing a DFA generally produces an NFA (several old accepts, hence several new starts). Determinise afterwards if a DFA is required. The language of `a*b*` reversed is `b*a*`, not `{b^n a^n}`.

## 3. What is *not* closed

| Operation | Regular? | Counter-example |
|---|---|---|
| Infinite union | no | `⋃_{n≥0} {a^n b^n} = {a^n b^n}`: each singleton is finite, hence regular |
| Infinite intersection | no | `⋂_{n≥0} (Σ* − {a^n b^n}) = Σ* − {a^n b^n \| n ≥ 0}`, whose complement is not regular |
| Subset | no | `{a, b}*` is regular; `{a^n b^n}` is a non-regular subset |
| `{ ww \| w ∈ L }` | no | `L = a*b` is regular; `{a^n b a^n b \| n ≥ 0}` is not |
| `{ ww^R \| w ∈ L }` | no | `L = {a, b}*` is regular; even-length palindromes are not |
| Substitution that copies a block | no | the same `ww` example |

Finite union *is* closed: fold the two-argument union. The 2020 / 2007 trap is to treat “closed under union” as “closed under *arbitrary* union”.

If `L ∪ M` is regular, neither `L` nor `M` need be: take `L = {a^n b^n}` and `M = {a, b}*`. The union is `{a, b}*`. The same example shows that a regular union does not let you cancel a regular summand and conclude that the other summand is regular.

If `L*` is regular, `L` need not be. Take any non-regular `L` that contains both `a` and `b` (for example `{a^n b^n \| n ≥ 1} ∪ {a, b}`). Then `L* = {a, b}*`, which is regular, while `L` itself is not (intersect with `a*b*` and delete a finite set).

## 4. Finite ⇒ regular; regular ⇒ decidable

- Every finite language is regular. So every finite subset of a *non-regular* language is regular (2007 pattern). Infinite subsets need not be.
- Regular languages are closed under complement, so a language is regular if and only if its complement is. Hence: if `L` is not regular, then `L̄` is not regular (2024 pattern). Context-free languages do **not** have this property.
- For regular languages the following are decidable: membership, emptiness, finiteness, universality (`L = Σ*`?), equivalence, inclusion. The algorithms go through a DFA (reachability of an accept state; a cycle on a path to an accept; equality of minimal DFAs). Do not copy these facts onto CFLs or TMs.

## 5. Independent exponents versus equal / crossed exponents

A language of the form `{ a^n b^m \| n, m ≥ 0 }` is `a*b*`: the two counts are **independent**. A two-state-plus-sink DFA remembers “still in the `a`-block / moved to the `b`-block / saw a late `a`”.

A language that **equates** or **crosses** two unbounded counts is not regular.

| Language | Regular? | Reason |
|---|---|---|
| `{ a^n b^m \| n, m ≥ 0 }` | yes | `a*b*` |
| `{ a^n b^m c^k \| n, m, k ≥ 0 }` | yes | `a*b*c*` |
| `{ a^n b^n \| n ≥ 0 }` | no | MN: `a^i` distinguished from `a^j` by `b^i` |
| `{ a^n b^{2n} \| n ≥ 0 }` | no | same, continuation `b^{2i}`; it *is* CFL (`S → aSbb \| ε`) |
| `{ a^n b^m \| n ≠ m }` | no | if it were, then `a*b*` minus that set `= {a^n b^n}` would be regular |
| `{ a^n b^m \| n = 2m }` | no | equal after a homomorphism, or MN on `a^{2i}` |
| `{ w ∈ {a, b}* \| #_a(w) ≡ r (mod p), #_b(w) ≡ s (mod q) }` | yes | product of a `p`-cycle and a `q`-cycle |
| `{ w ∈ {a, b}* \| #_a(w) ≡ r (mod p) and #_a(w) = #_b(w) }` | no | intersection with `a*b*` is `{ a^{pk+r} b^{pk+r} }` |

**Intersection with a regular language is the classification scalpel.** If `L` were regular, then `L ∩ R` would be regular for every regular `R`. To prove `L` is not regular, pick an `R` that carves out a known non-regular core (`a*b*`, `ab*ab*`, `a*ca*`, …).

Worked instance (2025 CS2 shape). Let `Σ = {a, b, c}`.

- `{a^m b^n \| m, n ≥ 0}` is regular.
- `{a, b}* ∩ { a^m b^n c^{m−n} \| m ≥ n ≥ 0 }`: a string with no `c` forces `m − n = 0`, so the intersection is `{a^m b^m}`, not regular.
- `#_a ≡ 2 (mod 7)` and `#_b ≡ 3 (mod 9)`: a `7 × 9` product DFA. Regular.
- `#_a ≡ 2 (mod 7)` and `#_a = #_b`: equal counts with a modular constraint, still not regular.

## 6. Prefix, suffix, quotient, homomorphism

Let `L` be regular.

**Prefix.** `Prefix(L) = { x \| ∃ y, xy ∈ L }`. Construction: from a DFA for `L`, make every state that *can reach* an original accept into an accept. Reachability is decidable, so the new DFA is regular.

**Suffix.** `Suffix(L) = { y \| ∃ x, xy ∈ L }`. Reverse, take prefixes, reverse; or an NFA that may start from any state of the original DFA (new start with ε-edges into every state).

**Right quotient by a string.** `L / a = { x \| xa ∈ L }`. Move the start state along `a` (or, for a DFA, take as new accepts those states from which `a` lands in an old accept). Quotient by a regular language is also regular: a state `q` of `A` becomes accepting if `L(A_q) ∩ M ≠ ∅` for the quotient language `M`.

**Concatenation versus copy.** If `L` is regular then `L · L` and `L · L^R` are regular (closed under reverse and concatenation). The languages `{ ww \| w ∈ L }` and `{ ww^R \| w ∈ L }` are *not* concatenations: they require the two halves to be the *same* string. For `L = {a, b}*` the second is the even-length palindromes, not regular (2019 pattern). If `L` is finite then `{ww \| w ∈ L}` is finite, hence regular.

**Homomorphism** `h: Σ* → Γ*` is determined by the words `h(a)` for `a ∈ Σ`, extended by `h(xy) = h(x)h(y)` and `h(ε) = ε`. Regular languages are closed under `h` and under `h^{-1}`. Homomorphism can hide a non-regular core (it can map `{a^n b^n}` onto `{(ab)^n}`, which is regular), so a regular image does not prove the source was regular. Inverse homomorphism preserves regularity in the useful direction: if `L` is regular then `h^{-1}(L)` is regular.

## 7. Regular grammars (right-linear / left-linear)

A grammar is **right-linear** if every production is `A → xB` or `A → x` with `x ∈ Σ*`. It is **left-linear** if every production is `A → Bx` or `A → x`.

- Right-linear grammars generate exactly the regular languages (the non-terminal is the NFA state).
- Left-linear grammars generate the same family (they are the reverse of right-linear grammars, and reverse preserves regularity).
- A grammar that uses *both* a left-linear and a right-linear production can generate a non-regular language. The standard example is `{a^n b^n}`: `S → aB`, `B → Sb \| b` (one production puts the non-terminal on the right, another on the left).

**LL(1) versus LR(1)** (mapped 2007 question, compilers vocabulary used on a regular-grammar stem).

- Left-linear grammars are typically left-recursive (`S → S0 \| 1`). Left-recursive grammars are not LL(1). So “every regular grammar is LL(1)” is false. (`S → S0 \| 1` is **left**-linear, not right-linear.)
- Every regular language is a deterministic CFL (a DFA is a DPDA that ignores the stack). Every DCFL has an LR(1) grammar. So every regular *set* has an LR(1) grammar. (The given grammar might be the wrong one; some regular grammar for the same set is LR(1).)

## 8. Myhill–Nerode — the test that can prove regularity

Define `x ≡_L y` if and only if for every continuation `z ∈ Σ*`,

`xz ∈ L  ⇔  yz ∈ L`.

This is an equivalence relation on `Σ*`. Two strings are **distinguishable** when some `z` puts exactly one of `xz`, `yz` into `L`.

**Myhill–Nerode theorem.** `L` is regular if and only if `≡_L` has finitely many classes. The number of classes equals the number of states of the minimal complete DFA.

- Infinitely many pairwise distinguishable strings ⇒ not regular. This is the usual written proof for `{a^n b^n}`: `a^i` and `a^j` (`i ≠ j`) are distinguished by `b^i`.
- Finitely many classes ⇒ regular: the classes *are* the DFA states. From the class of `x`, the letter `a` goes to the class of `xa`. The transition is well-defined because `x ≡_L y` implies `xa ≡_L ya`. Accepting classes are those of strings that belong to `L`.

Pumping cannot do the second direction. If a question asks you to *prove* a language is regular, give a DFA / NFA / RE / right-linear grammar, or exhibit finitely many MN classes. Do not pump.

**Worked distinguishability.** Language of strings over `{a, b}` that start with `b` and contain an even number of `a`s. Four classes, so the minimal complete DFA has four states:

| Class representative | Meaning | Accept? |
|---|---|---|
| `ε` | nothing read | no |
| `a` | started with `a` (dead) | no |
| `b` | started with `b`, even `#a` | yes |
| `ba` | started with `b`, odd `#a` | no |

`ε` distinguishes the accept class from the other three. `b` distinguishes `ε` from `ba` and from `a`. `a` distinguishes `ba` from `a`. The rejecting sink is required in a *complete* DFA because the start state has an `a`-transition that must land somewhere that can never accept.

## 9. Copy languages: when `αβα` collapses, and when it does not

Let

`L1 = { αβα \| α ∈ {a, b}+, β ∈ {a, b}+ }`,
`L2 = { αβα \| α ∈ {a}+, β ∈ {a, b}+ }`.

(2025 CS1 shape.)

**`L2` is regular.** Every member starts and ends with `a` and has length at least 3 (`|α| ≥ 1`, `|β| ≥ 1`). Conversely, take any string `w = a x a` with `|x| ≥ 1`. Set `α = a` (which lies in `{a}+`) and `β = x`. Then `αβα = w`. So

`L2 = a (a + b)+ a`

— all strings over `{a, b}` that start and end with `a` and have length at least 3. The shortest legal `α`, a single `a`, **always works**. A longer matching run of `a`s is optional, never required, so there is no unbounded copy to remember.

**`L1` is not regular.** Taking `|α| = 1` only produces the strings of length ≥ 3 whose first and last symbols are equal, which *is* a regular *subset* of `L1`. But `α` may be mixed, so `L1` also contains strings whose first and last symbols differ, for example `α = ab`, `β = a` gives `abaab`. Those extra members are the ones that force a genuine copy of a binary block.

A clean non-regularity proof uses intersection with a regular language. Let `R = ab*ab*` (exactly two `a`s). Then

`L1 ∩ R = { a b^i a b^j \| i > j ≥ 0 }`.

Why `i > j`: a string `a b^i a b^j` has exactly two `a`s, so in a parse `αβα` the block `α` contains exactly one `a` and `β` contains none (otherwise the `a`-count would exceed 2). Since the string starts with `a`, one has `α = a b^j` and `β ∈ b+`, hence `i = j + |β| > j`. Conversely every such string is `αβα` with that parse. The language `{ a b^i a b^j \| i > j }` is not regular (the two `b`-blocks remember an unbounded comparison). If `L1` were regular, the intersection would be regular.

The slogan: **unary `α` collapses to a local regular condition on the first and last letters; mixed `α` is a copy and is not regular.**

## 10. Closure-arithmetic patterns the papers reuse

**Intersection regular, one factor regular (2026 shape).** Suppose `L1 ∩ L2` and `L2` are regular. Then `L2` is regular, hence context-free. Nothing forces `L1` to be regular or even context-free: take `L2 = ∅` (regular) and `L1` any non-CFL; the intersection is `∅`. If a non-empty `L2` is wanted, take `L1 = N ∪ L2` with `N ∩ L2 = ∅` and `N` a non-CFL; then `L1 ∩ L2 = L2`. The union `L1 ∪ L2` equals `L1` in the empty-`L2` example, so it need not be regular.

**Equality versus inclusion (2024 shape).** For regular `L1, L2`,

`L1 ∩ L̄2 = ∅  ⇔  L1 ⊆ L2`,

which is *not* `L1 = L2`. Equality needs both differences empty. `L̄1 ∪ L̄2` is regular because regular languages are closed under complement and union. `L1 ∪ L3` need not be non-regular when `L3` is not: if `L3 ⊆ L1` the union is `L1`. The complement of a non-regular language *is* non-regular, by closure under complement.

**Concatenation of unary regular sets (2014 shape).** `{a^n \| n ≥ 0} · {b^n \| n ≥ 0} = a* b*`, which is regular, and it is **not** equal to `{a^n b^n}`. Concatenation does not reuse the same integer `n`.

**Four-set classification (2008 shape).**

| Set | Regular? |
|---|---|
| `{ a^n b^m \| n, m ≥ 0 }` | yes (`a*b*`) |
| `{ a^n b^m \| n = 2m }` | no |
| `{ a^n b^m \| n ≠ m }` | no (complement relative to `a*b*` is `{a^n b^n}`) |
| `{ x c y \| x, y ∈ {a, b}* }` | yes (`(a+b)* c (a+b)*`) |

## GATE problem-solving approach

1. **Translate the set into a constraint on counts or on a pattern.** Independent counts → regular; one unbounded equality or a copy of a mixed block → not regular.
2. **To prove regular:** write an RE, a DFA (what a state remembers), a right-linear grammar, or finitely many MN classes. Finite is enough.
3. **To prove not regular:** infinitely many distinguishable prefixes, or intersect with a regular language and reduce to `{a^n b^n}` / a copy. Pumping is the other tool ([07](../07-PUMPING-LEMMA/)).
4. **Closure questions.** Write a one-line construction for “always regular”. For “not always”, give a two-language counter-example. Check whether the operation is *finite* union or *infinite* union.
5. **Never cancel a regular operand.** `L ∪ R` regular and `R` regular does not imply `L` regular. The same for intersection in the other direction: if `L ∩ R` is *not* regular and `R` is regular, then `L` is not regular (contrapositive of closure). If `L ∩ R` *is* regular, `L` may still fail to be.

## Common traps (summary)

- `{a^n}{b^n}` is not `{a^n b^n}`.
- `a*b*` is regular; `{a^n b^n}` is not; `{a^n b^m \| n ≠ m}` is not either.
- Union / intersection of two non-regular languages can be regular (`L` and `L̄`; `L` and `Σ*`).
- Infinite union of regular languages need not be regular; finite union is.
- Every subset of a regular language need not be regular; every *finite* subset of anything is regular.
- `L*` regular does not imply `L` regular.
- `{ ww \| w ∈ L }` is not `L · L`.
- Complement-swap on an NFA is not complement.
- Mixed-`α` copy is not regular; unary-`α` copy may collapse to a regular “starts-and-ends-with” language.
- `#_a ≡ r (mod p)` is regular; `#_a = #_b` is not; putting both constraints together does not become regular.
- Left-recursive regular grammars are not LL(1); the *language* still has an LR(1) grammar.

## Edge cases

- `∅` is regular and CFL. Using `L2 = ∅` is a legal counter-example in “always true?” questions.
- `Σ*` is regular; it swallows every union.
- Unary regular languages are finite unions of arithmetic progressions (ultimately periodic length sets). `{ a^{n^2} }` and `{ a^{n!} }` are not regular.
- Completeness of a DFA: sinking “illegal” strings adds a state that Myhill–Nerode will also count if that sink is reachable.

## Connections

- **Regular expressions** (01): one of the three Kleene presentations. Closure constructions often go DFA → RE or RE → ε-NFA.
- **Finite automata** (02): min-DFA size = number of MN classes. “How many states?” belongs there; “is it regular?” belongs here.
- **Pumping lemma** (07): necessary condition used to prove *non*-regularity. It does not replace Myhill–Nerode or a DFA.
- **Context-free languages** (06): regular ⊂ CFL. Closed under union, concatenation, star; *not* under complement or intersection. Intersection of a CFL with a regular language *is* a CFL — the same scalpel as Section 5, one level up.
- **Context-free grammars** (03): right-linear grammars sit inside CFGs. Mixed linear productions can leave the regular family.
- **Undecidability** (09): everything listed in Section 4 is decidable for regular languages and becomes harder for CFLs / TMs. Do not export a DFA algorithm to a TM stem.
