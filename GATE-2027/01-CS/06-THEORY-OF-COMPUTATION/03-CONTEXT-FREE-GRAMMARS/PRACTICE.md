Original GATE-style questions written for this repository. They are not previous-year questions. They do not repeat the questions in `../../14-PRACTICE-QUESTIONS/TOPIC-WISE/06-THEORY-OF-COMPUTATION/03-CONTEXT-FREE-GRAMMARS/practice.md`; do both sets.

Every numerical answer below was checked by listing the derived strings or by an invariant proved on the productions. Open the answer block only after attempting the question.

## Level 1 — Conceptual

### Q1 · MCQ

The grammar `S → 0S1 | 00` does **not** generate

- (A) `00`
- (B) `0001`
- (C) `0011`
- (D) `000011`

<details><summary>Answer and solution</summary>

**Answer:** (C)

**Solution:** Each use of `S → 0S1` wraps one `0` on the left and one `1` on the right; `S → 00` stops. The strings are `{ 0^{n+2} 1^n | n ≥ 0 }`.

- `00`: `n = 0`.
- `0001`: `n = 1`.
- `000011`: `n = 2`.
- `0011` is `0^2 1^2`, which would need `n + 2 = 2` and `n = 2` together — impossible.

**Concept tested:** reading a wrapping grammar.
**Difficulty:** Level 1
**Common trap:** treating it as `{ 0^n 1^n }` or as `0*1*`.
</details>

### Q2 · MCQ

`S → XY`, `X → 0X | 0`, `Y → 1`. Which derivation of `001` is leftmost?

- (A) `S ⇒ XY ⇒ 0XY ⇒ 00Y ⇒ 001`
- (B) `S ⇒ XY ⇒ X1 ⇒ 0X1 ⇒ 001`
- (C) `S ⇒ XY ⇒ 0XY ⇒ 0X1 ⇒ 001`
- (D) `S ⇒ XY ⇒ 0Y ⇒ 00Y ⇒ 001`

<details><summary>Answer and solution</summary>

**Answer:** (A)

**Solution:** Leftmost means the leftmost variable is rewritten at every step. (A) expands `S`, then `X`, then `X`, then `Y`.

(B) expands `Y` while `X` is still to its left. (C) expands `Y` while `X` remains. (D) is illegal: `X → 0Y` is not a production, and `X → 0` would give `S ⇒ XY ⇒ 0Y ⇒ 01`, not `00Y`.

**Concept tested:** leftmost vs any derivation.
**Difficulty:** Level 1
**Common trap:** (B) is a legal right-first derivation of the **same** tree; it is not leftmost.
</details>

### Q3 · NAT

The number of strings of length 5 generated by `S → aSb | c` is ____.

<details><summary>Answer and solution</summary>

**Answer:** 1

**Solution:** Every sentence is `a^n c b^n`, of length `2n + 1`. Length 5 forces `n = 2`, so the only string is `aacbb`.

**Concept tested:** wrapping plus a centre terminal; odd length.
**Difficulty:** Level 1
**Common trap:** counting `aabbc` or `abcba`, which this grammar cannot mix.
</details>

### Q4 · MCQ

Which statement is true?

- (A) Every sentential form is a sentence
- (B) `ε` cannot be a sentential form
- (C) The start symbol is a sentential form
- (D) A production may have a terminal as its left-hand side

<details><summary>Answer and solution</summary>

**Answer:** (C)

**Solution:** `S ⇒* S` in zero steps, so `S` is a sentential form. A sentence is a sentential form with no variables, so (A) is false. `S ⇒* ε` is possible, so `ε` can be a sentential form. The left-hand side of a CFG production is a variable.

**Concept tested:** sentential form vs sentence.
**Difficulty:** Level 1
**Common trap:** thinking a sentential form must contain a variable (it need not: sentences are sentential forms).
</details>

## Level 2 — Standard GATE

### Q5 · MCQ

`S → 0A | 11B`, `A → 0A | 1`, `B → 1B | 0`. Then `L(S)` is

- (A) `{ 0^m 1 | m ≥ 1 } ∪ { 1^k 0 | k ≥ 2 }`
- (B) `{ 0^m 1 | m ≥ 0 } ∪ { 1^k 0 | k ≥ 1 }`
- (C) `{ 0^n 1^n | n ≥ 1 }`
- (D) `{ 0^m 1^k 0 | m, k ≥ 1 }`

<details><summary>Answer and solution</summary>

**Answer:** (A)

**Solution:** `A` is `0* 1`. `S → 0A` therefore requires at least one leading `0`, so `{ 0^m 1 | m ≥ 1 }`. `B` is `1* 0`. `S → 11B` contributes two extra leading `1`s, so `{ 1^k 0 | k ≥ 2 }`. Union is (A).

(B) includes `1` (`m = 0`) and `10` (`k = 1`), neither of which is generated. (C) and (D) mix the two arms.

**Concept tested:** reading two arms; `≥ 1` vs `≥ 0`.
**Difficulty:** Level 2
**Common trap:** dropping the forced leading `0` or the two forced leading `1`s.
</details>

### Q6 · MSQ

Start symbol `S`:

```
S → 0A | 1
A → 0A | 2
B → 3B
C → 4
D → C D | 5
```

Which variables are useless? Select all that apply.

- (A) `A`
- (B) `B`
- (C) `C`
- (D) `D`

<details><summary>Answer and solution</summary>

**Answer:** (B), (C), (D)

**Solution:** Generating: `A ⇒ 2`, `C ⇒ 4`, `D ⇒ 5`, `S ⇒ 1`. `B → 3B` never eliminates `B`, so `B` is not generating. Delete `B` and `B → 3B`.

From `S` the remaining reachable variables are `S` and `A`. `C` and `D` are unreachable, hence useless. `A` is used in `S ⇒ 0A ⇒ 02`.

**Concept tested:** generating first, then reachable.
**Difficulty:** Level 2
**Common trap:** calling `C` useful because `C ⇒ 4`, or calling `A` useless because `A` is not `S`.
</details>

### Q7 · MCQ

Which grammar is in Chomsky normal form?

- (A) `S → AB`, `A → BC`, `B → 0`, `C → 1`
- (B) `S → 0B`, `B → 1`
- (C) `S → A`, `A → 0`
- (D) `S → ABC`, `A → 0`, `B → 1`, `C → 0`

<details><summary>Answer and solution</summary>

**Answer:** (A)

**Solution:** CNF allows `A → BC` and `A → a` only. (A) has exactly those shapes. (B) is `S → 0B`. (C) is a unit production. (D) has three variables on a right-hand side.

**Concept tested:** CNF shape.
**Difficulty:** Level 2
**Common trap:** accepting a linear production `A → aB` because it “looks normal”.
</details>

### Q8 · NAT

A CFG in Chomsky normal form has 7 variables and derives `w` with `|w| = 8`. The number of steps in any derivation `S ⇒* w` is ____.

<details><summary>Answer and solution</summary>

**Answer:** 15

**Solution:** For `|w| = n ≥ 1` every CNF derivation has `2n − 1` steps: `n` terminal productions and `n − 1` binary productions. Here `n = 8`, so `15`. The 7 variables are unused.

**Concept tested:** CNF step count; `|V|` red herring.
**Difficulty:** Level 2
**Common trap:** answering 7, 8, or `8 + 7`.
</details>

### Q9 · MCQ

The language of `S → 0S1S | ε` is

- (A) `{ 0^n 1^n | n ≥ 0 }`
- (B) every string over `{0,1}` with equally many `0`s and `1`s
- (C) every string over `{0,1}` with equally many `0`s and `1`s in which every prefix has at least as many `0`s as `1`s
- (D) `{ (01)^n | n ≥ 0 }`

<details><summary>Answer and solution</summary>

**Answer:** (C)

**Solution:** Dyck words on `0`/`1`. `ε` is in; `S ⇒ 0S1S ⇒ 01` is in; `S ⇒ 0S1S ⇒ 0 01 1 ε = 0011` and `S ⇒ 0S1S ⇒ 0 ε 1 01 = 0101` are in. `10` has equal counts and is not generated (a prefix with more `1`s). So not (B). Not only `{ 0^n 1^n }` because `0101` is in. Not only `(01)*` because `0011` is in.

**Concept tested:** Dyck vs equal-count vs `{0^n 1^n}`.
**Difficulty:** Level 2
**Common trap:** (B), which is the 2007-style equal-count grammar, not this one.
</details>

## Level 3 — Multi-Step

### Q10 · MSQ

```
S → 1 A 1
A → 0 A 0 | 1
```

Which statements are true? Select all that apply.

- (A) Every string in `L(S)` contains exactly three `1`s
- (B) Every string in `L(S)` has equally many `0`s and `1`s
- (C) In every string in `L(S)` the number of `0`s is even
- (D) `11011 ∈ L(S)`

<details><summary>Answer and solution</summary>

**Answer:** (A), (C)

**Solution:** `A` generates `0^k 1 0^k` for `k ≥ 0`. Then `S` generates `1 0^k 1 0^k 1`. Always three `1`s. The number of `0`s is `2k`, even. Equal counts fail: `111` has three `1`s and no `0`s. `11011` is not of the form `10^k 10^k 1` (the two `0`-blocks would have to be equal and sit between the three `1`s: `10101` for `k = 1`, `111` for `k = 0`).

**Concept tested:** count invariant from productions.
**Difficulty:** Level 3
**Common trap:** (B) after noticing the balanced `0`s of `A` and forgetting `S`’s two extra `1`s.
</details>

### Q11 · NAT

In `S → S + S | x`, the number of distinct leftmost derivations of `x + x + x` is ____.

<details><summary>Answer and solution</summary>

**Answer:** 2

**Solution:** The first step must be `S ⇒ S + S`. Leftmost then fully expands the left `S` before the right `S`. The splits of three `x`s into a non-empty left piece and a non-empty right piece are `1+2` and `2+1`.

- Left derives `x`, right derives `x + x`: one leftmost way to derive a single `x`, and one leftmost way to derive `x + x` (`S ⇒ S + S ⇒ x + S ⇒ x + x`).
- Left derives `x + x`, right derives `x`: symmetrically one way.

Total 2. (These are the two associations `(x + x) + x` and `x + (x + x)`.) A split `3+0` is illegal because both sides of `S + S` are non-empty.

**Concept tested:** leftmost derivations / Catalan `C_2 = 2`.
**Difficulty:** Level 3
**Common trap:** counting 5 (the count for four letters) or counting non-leftmost orders as extra.
</details>

### Q12 · MCQ

`G1`: `S → Sa | B`, `B → b | bB`.  
`G2`: `S → aA | b`, `A → aA | B | ε`, `B → bB | ε`.

The pair `(L(G1), L(G2))` is

- (A) `{ b^n a^m | n ≥ 1, m ≥ 0 }` and `{ a^m b^n | m ≥ 1, n ≥ 1 } ∪ {b}`
- (B) `{ b^n a^m | n ≥ 1, m ≥ 0 }` and `{ a^+ b^* } ∪ {b}`
- (C) `{ a^m b^n | m ≥ 0, n ≥ 1 }` and `{ a^m b^n | m > 0 or n > 0 }`
- (D) `{ b^+ a^* }` and `{ a, b }*`

<details><summary>Answer and solution</summary>

**Answer:** (B)

**Solution:** `G1`: any number of trailing `a`’s (including zero), then `B` which is `b+`. Order is `b`’s then `a`’s: `{ b^n a^m | n ≥ 1, m ≥ 0 } = b^+ a^*`.

`G2`: `S → aA` gives at least one `a`, then `A` may add `a`’s and finish with `ε` or `B = b*`, so `a+ b*`. `S → b` adds the single string `b`. Union: `a+ b* ∪ {b}`. It does **not** contain `bb` (`S → b` is a terminal production, and `B` is reachable only through `A`, which is reachable only through a leading `a`). It does not contain `ε`.

(A)’s second component `{ a^m b^n | m ≥ 1, n ≥ 1 } ∪ {b}` forces a positive number of `b`’s on the `a+` arm, missing `aa`. (C) is a leading-`a` then `b`’s pair, not this trailing-`a` grammar. (D) lets `G2` generate everything.

**Concept tested:** two grammars; trailing vs leading letters; a singleton extra production.
**Difficulty:** Level 3
**Common trap:** letting `G2` generate `b+` because `B → bB | ε` exists — `B` is not reachable from `S` without a leading `a`, except that `S → b` adds one `b` only.
</details>

### Q13 · MCQ

`S → 0S1 | X`, `X → 2`. Which statement is true?

- (A) `L(S) = 0* 2 1*`
- (B) `L(S) = { 0^n 2 1^n | n ≥ 0 }`, and this language is regular
- (C) `L(S) = { 0^n 2 1^n | n ≥ 0 }`, and this language is not regular
- (D) `L(S) = (0 + 1 + 2)*`

<details><summary>Answer and solution</summary>

**Answer:** (C)

**Solution:** `X` contributes only the centre `2`. The wrap adds matching `0`s and `1`s, so `{ 0^n 2 1^n | n ≥ 0 }`. The strings `0^n` are pairwise distinguishable by the continuation `2 1^n`, so the language is not regular.

Contrast: if `X` itself generated `0*(2)1*` with free counts, the wrap would be absorbed and the language would be regular. A rigid single terminal cannot absorb the wrap. `0211` is not generated, so not `0*21*`.

**Concept tested:** wrap-absorption fails when the inner variable cannot grow.
**Difficulty:** Level 3
**Common trap:** (A) or (B), copying the 2023 conclusion without checking `X`.
</details>

## Level 4 — Tricky / Trap-Based

### Q14 · MSQ

Which statements are true? Select all that apply.

- (A) If a CFG is ambiguous, its language is inherently ambiguous
- (B) `{ a^i b^j c^k | i = j or j = k }` is context-free and inherently ambiguous
- (C) Every regular language has an unambiguous CFG
- (D) `S → SS | 0` is an unambiguous grammar for `0+`

<details><summary>Answer and solution</summary>

**Answer:** (B), (C)

**Solution:** (A) is false: `S → SS | 0` is an ambiguous grammar for the regular language `0+`, which also has the unambiguous grammar `A → 0A | 0`. (B) is the standard inherently ambiguous CFL (union of two CFLs; strings with `i = j = k` have two parses in every grammar). (C) is true: a DFA converts to an unambiguous right-linear grammar. (D) is false: `00` has `S ⇒ SS ⇒ 0S ⇒ 00` and `S ⇒ SS ⇒ S0 ⇒ 00`.

**Concept tested:** ambiguity vs inherent ambiguity; regular languages are not inherently ambiguous.
**Difficulty:** Level 4
**Common trap:** (A) and (D).
</details>

### Q15 · NAT

```
S → 0A | 1
A → 0A | 0
B → 1B
C → 2
```

After useless symbols are eliminated in the correct order, the number of productions that remain is ____.

<details><summary>Answer and solution</summary>

**Answer:** 4

**Solution:** Generating: `A ⇒ 0`, `C ⇒ 2`, `S ⇒ 1`. `B → 1B` never terminates. Delete `B` and `B → 1B`. Remaining:

```
S → 0A | 1
A → 0A | 0
C → 2
```

From `S` the reachable variables are `S` and `A`. Delete `C → 2`. Four productions remain. Language `{ 0^+ } ∪ {1}`.

**Concept tested:** generating then reachable; counting surviving productions.
**Difficulty:** Level 4
**Common trap:** leaving `C → 2` because `C` generates, or deleting `A`.
</details>

### Q16 · MSQ

`S → xSyS | z`. For every `w ∈ L(S)`, which relations hold? Select all that apply.

- (A) `n_x(w) > n_y(w)`
- (B) `n_x(w) = n_y(w)`
- (C) `n_z(w) = n_y(w) + 1`
- (D) `n_z(w) = 2 n_y(w)`

<details><summary>Answer and solution</summary>

**Answer:** (B), (C)

**Solution:** Let `v` be the number of uses of `S → xSyS` and `t` the number of uses of `S → z`. Each `xSyS` changes the live-`S` count by `+1`; each `z` by `−1`. Starting from one `S` and ending at none: `v − t = −1`, so `t = v + 1`. Letter counts: `n_x = v`, `n_y = v`, `n_z = t = v + 1`. Thus `n_x = n_y` and `n_z = n_y + 1`.

(A) fails on `z` and on `xzyz`. (D) requires `v + 1 = 2v`, i.e. `v = 1` only; `z` fails.

**Concept tested:** production-use accounting (same method as `S → aS | aSbS | c`, different grammar: no unary `aS` arm, so equality of `n_x` and `n_y` is forced).
**Difficulty:** Level 4
**Common trap:** (A) from analogy with a grammar that has an extra unary production.
</details>

## Level 5 — Challenge

### Q17 · MCQ

Which language is inherently ambiguous?

- (A) `{ 0^n 1^n | n ≥ 0 }`
- (B) `{ 0, 1 }*`
- (C) `{ 0^i 1^j 2^k | i = j or j = k }`
- (D) `{ 0^n 1^n 2^n | n ≥ 0 }`

<details><summary>Answer and solution</summary>

**Answer:** (C)

**Solution:** (C) is the union of two CFLs `{ 0^n 1^n 2^* }` and `{ 0^* 1^n 2^n }`, hence CFL, and is the standard inherently ambiguous example. (A) has the unambiguous grammar `S → 0S1 | ε`. (B) is regular, hence has an unambiguous right-linear grammar. (D) is not context-free, so “inherently ambiguous” (a property of CFLs) does not apply.

**Concept tested:** inherent ambiguity requires the language to be CFL.
**Difficulty:** Level 5
**Common trap:** (D), or (B) because `S → SS | 0 | 1 | ε` is ambiguous.
</details>

### Q18 · NAT

The number of strings of length 4 generated by `S → aSbS | ε` is ____.

<details><summary>Answer and solution</summary>

**Answer:** 2

**Solution:** Non-empty members split uniquely as `a x b y` with `x, y` members and the `b` the first return of `#a − #b` to zero. Length 4 forces `|x| + |y| = 2` with both even (every member has even length).

- `|x| = 0`, `|y| = 2`: `y = ab`, string `a ε b ab = abab`.
- `|x| = 2`, `|y| = 0`: `x = ab`, string `a ab b ε = aabb`.

The two strings are `abab` and `aabb`. (Catalan `C_2 = 2` Dyck words of length 4.) `abba` has a prefix `abb` with more `b`s than `a`s and is out. `baaa` is out.

**Concept tested:** Dyck enumeration by first return.
**Difficulty:** Level 5
**Common trap:** counting 5 (length 6) or including `abba`.
</details>
