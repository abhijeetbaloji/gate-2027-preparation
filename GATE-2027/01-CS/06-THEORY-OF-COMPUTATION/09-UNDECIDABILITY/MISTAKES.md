# Undecidability — MISTAKES

| Mistake | Correct idea |
|---|---|
| Copy a TM fact onto a DFA or CFG | Name the model first |
| Undecidable ⇒ not RE | `A_TM` is RE |
| Rice on “has 5 states” | Not a property of `L(M)` |
| `A ≤ B` and `B` undecidable ⇒ `A` undecidable | Wrong direction |
| CFG membership undecidable | CYK |
| CFG emptiness undecidable | generating variables |
| `L(G)` is an undecidable language | The *set* `L(G)` is decidable; problems *about* `G` may not be |
| “> k steps on every input” undecidable | Finite window, `k` fixed |
| Some language in NP is undecidable | NP ⊆ decidable |
| Equivalence of two NFAs undecidable | Minimize |
