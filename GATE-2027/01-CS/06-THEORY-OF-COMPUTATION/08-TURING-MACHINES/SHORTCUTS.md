# Turing Machines — Shortcuts

## 1. Two bullets for “decides”
- Accept every yes **and** reject every no. Missing either bullet is only recognition (or a wrong language).

## 2. Finite check on the input ⇒ decidable
- Prime length, DFA run, CYK table: the procedure always stops.

## 3. “TM accepts all of L1, L2, L3”
- Almost always true for the standard counting languages. The false option is usually “all are CFL” or “PDA accepts L3”.
