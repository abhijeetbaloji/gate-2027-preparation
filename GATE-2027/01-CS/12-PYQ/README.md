# GATE CS previous-year question papers

This folder is the question-paper archive for GATE Computer Science & Information Technology (CS), from 2026 back to 2007.

GATE 2027 has not been conducted, so there is no 2027 paper here.

## Order

Years are stored newest first: 2026, then 2025, and so on down to 2007.

## What is in each paper folder

- `question-paper.pdf` is the question paper.
- `question-paper.md` identifies the paper and points to the PDF. It does not transcribe the questions. These papers contain mathematical notation, diagrams, tables, and program text, and a Markdown copy would change that notation.
- `source.md` records the year, paper, session, source type, website, direct URL, original title, date checked, and source notes.

No solutions, topic labels, or study notes are added. Where an official file had an answer key as separate trailing pages, those pages were not copied. Where the official file prints answer values on the same pages as the questions, the pages were kept as published and the note is in `source.md`.

Data Science and Artificial Intelligence (DA) papers are not in this folder.

## Missing or unavailable

- **2017 session 1 (CS-1, 11 February 2017, forenoon).** The official bulk archive contains `CS/CS1-2017.pdf`, and that file is not a readable PDF. No other official readable copy was found. A replacement was not taken from a secondary site, and the questions were not reconstructed.
- **2027.** Not held yet.
- **DA papers.** Not part of this CS archive.

## Multiple sessions

A year has `set-01`, `set-02`, and further set folders only when more than one distinct CS paper was held.

| Year | Sets |
| --- | --- |
| 2026 | set-01 CS-1 forenoon; set-02 CS-2 afternoon |
| 2025 | set-01 CS-1; set-02 CS-2 |
| 2024 | set-01 CS1; set-02 CS2 |
| 2021 | set-01 Set-1; set-02 Set-2 |
| 2017 | set-02 session 2 only. set-01 is unavailable |
| 2016 | set-01 first paper; set-02 second paper |
| 2015 | set-01, set-02, and set-03 are the three shifts |
| 2014 | set-01 SET-1; set-02 SET-2; set-03 SET-3 |
| 2013 | set-01 through set-04 are sessions 1–4 |

Years not in that table have one CS paper, stored directly in the year folder.

Booklet codes on the 2011 and 2012 papers are order variants of one paper. They are not stored as extra sets.
