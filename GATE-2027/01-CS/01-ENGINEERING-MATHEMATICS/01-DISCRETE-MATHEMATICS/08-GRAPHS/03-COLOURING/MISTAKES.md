# Graphs: Colouring — Mistakes

## Common Mistakes

| Trap | Wrong reasoning | Correct rule |
|------|-----------------|--------------|
| χ ≤ Δ | Always true | **False** — odd cycles: Δ=2, χ=3 |
| Bipartite | Any 2-regular graph bipartite | **C_5** is 2-regular, not bipartite |
| Tree χ | Always 2 | Single vertex: **χ = 1** |
| Empty graph | χ = 2 | **χ = 1** (no edges) |
| Brooks | χ ≤ Δ always | Exceptions: **K_n**, **odd cycles** |
| Greedy = optimal | Greedy count equals χ | Greedy is upper bound only |
| K_n colours | n−1 colours | **χ = n** |
| Edge vs vertex | Same symbols | χ vertex; **χ'** edge |
| Planar | χ ≤ 3 always | **χ ≤ 4** (Four Colour) |
| Clique bound | χ = ω always | χ ≥ ω; equality not guaranteed |
