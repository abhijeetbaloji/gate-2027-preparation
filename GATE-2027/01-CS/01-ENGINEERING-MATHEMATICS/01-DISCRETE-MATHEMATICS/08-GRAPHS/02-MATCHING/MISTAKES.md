# Graphs: Matching — Mistakes

## Common Mistakes

| Trap | Wrong reasoning | Correct rule |
|------|-----------------|--------------|
| Maximal vs maximum | Treat as same | Maximal ⊄ maximum in general |
| Perfect matching | \|V\| even ⇒ perfect exists | Need structural feasibility (Hall, etc.) |
| K_{m,n} | Matching = mn | Max matching = **min(m,n)** |
| Hall's theorem | \|A\| ≤ \|B\| ⇒ OK | Check **every** S ⊆ A: \|N(S)\| ≥ \|S\| |
| König everywhere | max matching = min cover always | **Bipartite only** |
| Star graph | Many leaves ⇒ large matching | Star: max matching **1** |
| Complete K_n | Matching n/2 for all n | Odd n: **(n−1)/2** |
| Counting K_{n,n} | C(n,n) or 2^n | Perfect matchings = **n!** |
| P_n perfect | Always perfect | Need **n even** |
| Bipartite assumed | All graphs bipartite for matching bounds | Verify **no odd cycle** |
