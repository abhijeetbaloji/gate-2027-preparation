# Combinatorics: Counting — Mistakes

## Common Mistakes

These are **general/common traps** — not personal error logs.


---

### General/common trap: Order vs combination


**What goes wrong:** Using C for passwords


**Correct rule:** Ordered → P or n^r


**Prevention:** Ask if rearranging changes outcome


---

### General/common trap: IEP three-set sign


**What goes wrong:** Subtract triple


**Correct rule:** Add triple intersection


**Prevention:** Memorize pattern
