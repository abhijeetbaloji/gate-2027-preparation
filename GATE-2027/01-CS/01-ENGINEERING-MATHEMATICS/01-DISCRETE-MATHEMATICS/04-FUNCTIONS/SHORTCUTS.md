# Functions — Shortcuts

Only use shortcuts **after** you understand `NOTES.md`.

---

### Shortcut: Onto to two elements


**Why it works:** IEP collapses


**When to use:** m elements → 2 outputs


**Example:** 2^m−2


**Trap / limitation:** Only for n=2

---

### Shortcut: Disprove injectivity


**Why it works:** One pair enough


**When to use:** Quick MCQ


**Example:** f(2)=f(−2) for n²


**Trap / limitation:** Need actual domain elements

---

### Shortcut: Finite A→A


**Why it works:** Pigeonhole equal size


**When to use:** |A| finite


**Example:** Injective ⇒ surjective


**Trap / limitation:** Infinite counterexamples exist

---

### Shortcut: Count 0 injections


**Why it works:** |A|>|B| impossible


**When to use:** Injection count


**Example:** 4→3 → 0


**Trap / limitation:** Forgetting to check possibility

---

### Shortcut: Bijection inverse


**Why it works:** Definition


**When to use:** Verify bijection


**Example:** Swap rules both ways


**Trap / limitation:** One direction only
