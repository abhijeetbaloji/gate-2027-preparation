# Functions — Mistakes

## Common Mistakes

These are **general/common traps** — not personal error logs.


---

### General/common trap: Codomain vs range


**What goes wrong:** Saying surjective because image subset of B


**Correct rule:** Surjective iff image equals codomain


**Prevention:** List uncovered elements


---

### General/common trap: n^m orientation


**What goes wrong:** Using |A|^|B|


**Correct rule:** |B|^|A|


**Prevention:** Outputs per input


---

### General/common trap: Composition order


**What goes wrong:** Computing f∘g when asked g∘f


**Correct rule:** Read left-to-right on argument


**Prevention:** Try one sample point
