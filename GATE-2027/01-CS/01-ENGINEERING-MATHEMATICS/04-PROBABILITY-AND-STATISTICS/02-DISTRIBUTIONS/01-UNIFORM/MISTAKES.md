# Uniform Distribution — Mistakes

## Common Mistakes

These are **general/common traps** — not personal error logs.

### General/common trap: Discrete vs continuous n

**What goes wrong:** Using n=b−a for discrete count

**Correct rule:** Discrete: n=b−a+1

**Prevention:** Count integers inclusively

---

### General/common trap: Variance formula swap

**What goes wrong:** Using (n²−1)/12 for continuous

**Correct rule:** Continuous: (b−a)²/12

**Prevention:** Match distribution type

---

### General/common trap: Point probability

**What goes wrong:** P(X=a) for continuous uniform

**Correct rule:** P(X=a)=0

**Prevention:** Use interval lengths
