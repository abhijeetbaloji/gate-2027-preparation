# Mode — Mistakes

## Common Mistakes

These are **general/common traps** — not personal error logs.

### General/common trap: Mode=mean

**What goes wrong:** Assuming mode near mean

**Correct rule:** Can differ greatly

**Prevention:** Exponential: mode 0, mean 1/λ

---

### General/common trap: Uniform discrete

**What goes wrong:** Single mode when all tie

**Correct rule:** All values modal

**Prevention:** No unique mode

---

### General/common trap: Continuous point prob

**What goes wrong:** P(X=mode)>0

**Correct rule:** P(X=x)=0 for continuous

**Prevention:** Mode is density peak
