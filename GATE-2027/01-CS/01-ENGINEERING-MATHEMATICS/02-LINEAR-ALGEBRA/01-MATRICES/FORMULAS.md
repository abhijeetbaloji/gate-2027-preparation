# Matrices — Formulas

| Rule | Formula | Use |
|------|---------|-----|
| Product size | (m×p)(p×n) → m×n | Dimension MCQs |
| Transpose of product | (AB)ᵀ = BᵀAᵀ | Simplify expressions |
| Inverse of product | (AB)⁻¹ = B⁻¹A⁻¹ | Reverse order |
| 2×2 inverse | (1/det)[[d,−b],[−c,a]] | Small matrices |
| det(kA) | kⁿ det(A) | Scalar multiple |
| Orthogonal | AᵀA = I, A⁻¹ = Aᵀ | Rotation/reflection |
| Trace | tr(A) = Σaᵢᵢ = Σλᵢ | Eigenvalue link |
| Rank bound | rank(A) ≤ min(m,n) | System solutions |
