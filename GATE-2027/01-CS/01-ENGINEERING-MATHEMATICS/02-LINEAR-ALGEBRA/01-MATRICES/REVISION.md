# Matrices — Quick Revision

- m×n matrix: m rows, n columns; product (m×p)(p×n) → m×n.
- (AB)ᵀ = BᵀAᵀ; (AB)⁻¹ = B⁻¹A⁻¹.
- Invertible ⇔ det ≠ 0 ⇔ full rank (square).
- Symmetric: Aᵀ = A; skew-symmetric: Aᵀ = −A (diag 0).
- Orthogonal: AᵀA = I ⇒ A⁻¹ = Aᵀ.
- Rank = independent rows = independent columns.
- tr(A) = sum of diagonal = sum of eigenvalues.
- 2×2 inverse: swap diagonal, negate off-diagonal, divide by det.
- det(kA) = kⁿ det(A).
