# Determinants — Formulas

| Rule | Formula | Use |
|------|---------|-----|
| 2×2 | ad − bc | Direct compute |
| Triangular | ∏ diagonal entries | After row reduction |
| Product | det(AB) = det(A)det(B) | Composite maps |
| Scalar | det(kA) = kⁿ det(A) | Scaling |
| Inverse | det(A⁻¹) = 1/det(A) | Invertibility |
| Eigenvalues | Πλᵢ = det(A) | Quick checks |
| Cramer's rule | xᵢ = det(Aᵢ)/det(A) | Small systems |
| Orthogonal A | det(A) = ±1 | Special matrices |
