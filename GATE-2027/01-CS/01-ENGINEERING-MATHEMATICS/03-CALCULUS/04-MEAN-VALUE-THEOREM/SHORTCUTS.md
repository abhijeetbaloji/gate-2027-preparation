# Mean Value Theorem — Shortcuts

## 1. Secant slope formula

- **Why it works**: (f(b)−f(a))/(b−a) is target f'(c)
- **When to use**: Find c or prove existence
- **Trap**: c in (a,b) not endpoints

## 2. Rolle when equal endpoints

- **Why it works**: f(a)=f(b) simplifies to f'(c)=0
- **When to use**: f(0)=f(1) type problems
- **Trap**: Check differentiability

## 3. |f(b)−f(a)| ≤ M|b−a|

- **Why it works**: MVT + |f'|≤M bound
- **When to use**: Estimate function change
- **Trap**: Need f' bound on whole interval

## 4. f'>0 ⇒ increasing

- **Why it works**: MVT gives f(b)>f(a) for b>a
- **When to use**: Monotonicity MCQs
- **Trap**: Strict if f'>0 not just ≥0

## 5. Auxiliary function for proof

- **Why it works**: g(x)=f(x)−kx shifts to Rolle form
- **When to use**: Proof-style questions
- **Trap**: Rare in GATE MCQ
