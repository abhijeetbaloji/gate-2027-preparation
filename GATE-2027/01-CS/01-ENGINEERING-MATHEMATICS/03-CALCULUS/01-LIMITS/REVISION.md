# Limits — Quick Revision

- **lim_{x→a} f(x) = L**: f(x) → L as x → a (x ≠ a OK).
- **Exists** iff left limit = right limit.
- **Standard:** sin x/x → 1; (eˣ−1)/x → 1; (1+x)^{1/x} → e; (1−cos x)/x² → 1/2.
- **∞ rational:** ratio of leading coefficients.
- **0/0:** factor → rationalize → L'Hôpital (check form).
- **L'Hôpital:** lim f/g = lim f'/g' for 0/0 or ∞/∞.
- **Squeeze:** g ≤ f ≤ h, same limit ⇒ f has that limit.
- **Trap:** |x|/x at 0 — DNE (±1).
