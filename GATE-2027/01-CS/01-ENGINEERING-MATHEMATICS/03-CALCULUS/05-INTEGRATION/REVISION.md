# Integration — Quick Revision

- **Indefinite:** ∫f dx = F(x) + C.
- **FTC:** ∫_a^b f(x)dx = F(b) − F(a) where F'=f.
- **Substitution:** u = g(x), change limits for definite.
- **Parts:** ∫u dv = uv − ∫v du (LIATE for u).
- **Average:** (1/(b−a))∫_a^b f.
- **Trap:** +C indefinite only; change substitution limits.
