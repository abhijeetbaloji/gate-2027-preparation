# Context-Free Grammars — Practice Questions

Original practice for GATE CS. These questions are not from any GATE paper. Attempt the questions before reading the solutions.

The empty string is `ε`. A leftmost derivation always expands the leftmost variable. A grammar is ambiguous when some string has two different leftmost derivations (equivalently, two parse trees).

## Detailed Solutions

### Q1

Answer: C

Each use of `S → aSb` wraps one `a` on the left and one `b` on the right, and `S → ε` stops. The generated strings are exactly `{a^n b^n | n ≥ 0}`.

Thus `ab`, `aabb`, and `aaabbb` are generated. The string `abab` is not of the form `a^n b^n`.

### Q2

Answer: A

A leftmost derivation expands the leftmost variable at every step.

(A) expands `S`, then the left variable `A`, then `A` again, and only then `B`:

`S ⇒ AB ⇒ aAB ⇒ aaB ⇒ aab`.

In (B) the second step expands `B` while `A` is still present and is to the left of `B`. In (C) the third step expands `B` while the remaining `A` is farther left. (D) is not even a legal derivation: `B → b` replaces `B` by `b`, not by `bB`, and `A → Ab` is not a production.

### Q3

Answer: 0

Every string derived from `S → aSb | c` has the form `a^n c b^n`, so its length is `2n + 1`, which is odd. There is no string of length 4.

### Q4

Answer: B

A derivation from the start symbol produces sentential forms, which may still contain variables. A sentence is a sentential form in which every symbol is a terminal. The left-hand side of a production is a variable, and the start symbol is a variable.

### Q5

Answer: A

Two leftmost derivations of the same string mean the grammar is ambiguous:

`S ⇒ SS ⇒ aS ⇒ ab`

`S ⇒ SS ⇒ Sb ⇒ ab`

The language is still context-free; ambiguity is a property of the grammar. The string `ab` is generated, and it does not have a unique leftmost derivation.

### Q6

Answer: B, C, D

A variable is useless when it does not occur in any derivation of a terminal string from `S`.

**Generating variables** (they derive at least one terminal string):

- `A ⇒ b`, so `A` generates.
- `C ⇒ c`, so `C` generates.
- `E ⇒ a`, so `E` generates.
- `B → bB` only. Every sentential form derived from `B` still contains `B`, so `B` does not generate.
- `S` generates, for example `S ⇒ d` and `S ⇒ aA ⇒ ab`.

Delete `B` and every production that mentions `B`, namely `B → bB` and `S → BC`. The remaining productions are

```
S → aA | d
A → aA | b
C → cC | c
E → a
```

From `S` the reachable variables are `S` and `A`. Both `C` and `E` are now unreachable, so they are useless as well.

`A` survives: `S ⇒ aA ⇒ ab` is a terminal derivation that uses `A`. The useless variables are `B`, `C`, and `E`.

### Q7

Answer: A

Chomsky normal form allows `A → BC` and `A → a` only. If `ε` is in the language, the only extra production permitted is `S → ε`, and then `S` must not appear on a right-hand side.

(A) has exactly the two allowed shapes. (B) has `S → aB`, a terminal followed by a variable. (C) has the unit production `S → A`. (D) has an `ε`-production for a variable other than the start symbol.

### Q8

Answer: A

Greibach normal form requires every production to look like `A → aα`, where `a` is a terminal and `α` is a (possibly empty) string of variables.

In (A), `S → aAB`, `A → a`, and `B → b` all have that shape. (B) starts with a variable. (C) ends with the terminal `b`, so the suffix is not a string of variables. (D) starts with a variable.

### Q9

Answer: 8

The grammar generates `(aa + bb)*`. A string of length 6 is three blocks, and each block is either `aa` or `bb`. There are `2^3 = 8` such strings:

`aaaaaa`, `aaaabb`, `aabbaa`, `aabbbb`, `bbaaaa`, `bbaabb`, `bbbbaa`, `bbbbbb`.

### Q10

Answer: B

Write a nonempty derivation as `S ⇒ aSbS`. The first `S` and the second `S` are themselves generated by the same grammar. By induction, every generated string has equally many `a`'s and `b`'s, and every prefix has at least as many `a`'s as `b`'s: the outer `a` is matched by its own `b`, and both inserted strings satisfy the prefix property.

Conversely, any nonempty string with that prefix property has a first position at which the running difference returns to zero. That position is a `b`, the interior is again such a string, and the suffix is again such a string. So the grammar generates exactly the balanced strings, including `ε`.

(A) is too large: `ba` has equally many of each letter and is not generated. (C) misses `abab`, which is `a ε b (a ε b)`. (D) misses the non-palindrome `abab` and would include the palindrome `ba`, which is not generated.

### Q11

Answer: A, B, C

Both `A` and `B` generate `a*b`, and each of those variables has a unique leftmost derivation of any such string: the production `→ aX` must be used once for every leading `a`, and then `→ b`.

Through `S → A` and through `S → B` one therefore gets two leftmost derivations of every string `a^n b`, and no more than two.

- `b`, `ab`, and `aab` all have the form `a^n b`.
- `ba` does not. Neither `A` nor `B` can produce a `b` before it has finished the leading `a`s, so `ba` is not generated at all.

### Q12

Answer: 5

Let `d(n)` be the number of leftmost derivations of `a^n`. Then `d(1) = 1`, by `S ⇒ a`. For `n ≥ 2` the first step must be `S ⇒ SS`. Because the derivation is leftmost, the left copy is expanded completely before the right copy. If the left copy produces `a^i` and the right copy produces `a^{n-i}`, then

`d(n) = d(1)d(n-1) + d(2)d(n-2) + … + d(n-1)d(1)`.

So `d(2) = d(1)d(1) = 1` and `d(3) = d(1)d(2) + d(2)d(1) = 2`. For `n = 4`,

`d(4) = d(1)d(3) + d(2)d(2) + d(3)d(1) = 2 + 1 + 2 = 5`.

The five derivations correspond to the five ways to split four leaves at the root and then split the subtrees. Different splits, or different derivations inside the same split, produce different sequences of leftmost steps.

### Q13

Answer: B

The normal-form algorithms are language-preserving. Useless productions do not participate in any terminal derivation, so deleting them leaves the language unchanged. Eliminating `ε`-productions and unit productions rewrites derivations but does not add or remove terminal strings.

Chomsky normal form exists for every context-free language, finite or not. Greibach normal form requires a terminal at the front of every right-hand side; it does not forbid terminals.

### Q14

Answer: B

Ambiguity of one grammar does not decide ambiguity of the language. The two-copy grammar gives each string `a^n` a derivation through `A` and a derivation through `B`, so it is ambiguous, while `A → aA | a` derives each `a^n` in exactly one way.

An inherently ambiguous language is one for which every grammar is ambiguous. Such a language is context-free and need not be regular. An ambiguous grammar still generates a context-free language by definition.

### Q15

Answer: 1

`B ⇒ b`, so `B` is generating. From `A` the only production is `A → AB`, so every sentential form derived from `A` still contains `A`. Thus `A` is not generating. `S` is generating because `S → a`.

Delete the non-generating variable `A` and both productions that mention it, `S → A` and `A → AB`. What remains is

```
S → a
B → b
```

`B` is not reachable from `S`. Delete `B → b`. The only remaining production is `S → a`.

The order matters. If unreachable symbols are deleted first, nothing is deleted: `S ⇒ A ⇒ AB` reaches both `A` and `B`. Deleting the non-generating variable `A` afterwards leaves `B → b` still written down, even though `B` has become unreachable. A second reachability pass is then required. Doing non-generating symbols first, then reachability once, leaves one production.

### Q16

Answer: B, C

(A) is false. The grammar in Q5 is ambiguous and still context-free. Ambiguity is not a failure of the context-free restriction.

(B) is true. A standard example is

`{a^i b^j c^k | i = j or j = k}`.

Every grammar for this language is ambiguous. The language is still context-free, as the union of `{a^i b^i c^k | i, k ≥ 0}` and `{a^i b^j c^j | i, j ≥ 0}`.

(C) is true. From a DFA, form the right-linear grammar whose variables are the states, with `A_q → a A_p` whenever `δ(q, a) = p`, and `A_f → ε` for each accept state `f`. Each string has exactly one run in a DFA, so it has exactly one leftmost derivation.

(D) is false. A useless production lies on no derivation of a terminal string, so deleting it preserves the language. Q15 is an example: deleting `S → A`, `A → AB`, and `B → b` still leaves the language `{a}`.

### Q17

Answer: B

The correct order is the one used in Q15: remove variables that derive no terminal string, together with every production that mentions them, and only then remove variables that the start symbol can no longer reach.

The opposite order can leave a newly unreachable variable behind, as `B` is left behind in Q15. A variable that derives a terminal string is still useless when no derivation from the start symbol can place it in a sentential form that eventually becomes terminal.

### Q18

Answer: B

From `T → aTb | A` and `A → aA | a`, every string derived from `T` has the form `a^j A b^j`, and `A` contributes `a^m` with `m ≥ 1`. So `T` generates `{a^{j+m} b^j | j ≥ 0, m ≥ 1}`, the strings `a^i b^j` with `i > j`.

From `U → aUb | B` and `B → bB | b`, the same counting gives `{a^j b^{j+m} | j ≥ 0, m ≥ 1}`, the strings with `j > i`.

These two families are disjoint, and their union is `{a^i b^j | i ≠ j}`, including the pure strings `a^m` (`j = 0`) and `b^m` (`i = 0`). The grammar does not generate `ε` or any string with `i = j`, such as `ab`. It also does not generate a string that is not of the form `a*b*`.

Option (A) misses the strings with more `b`s than `a`s. Option (C) includes `ab`. Option (D) is the complementary equality language.

### Q19

Answer: 5

A string generated by `S → aSbS | ε` has a unique first-return split when it is nonempty: `w = a x b y`, where `x` and `y` are generated by `S`, and the `b` is the first symbol that brings the running count of `a`s minus `b`s back to zero.

For `|w| = 6`, the possible lengths are `|x| ∈ {0, 2, 4}` and `|y| = 4 - |x|`.

- `|x| = 0`, `|y| = 4`. The length-4 strings are `aabb` and `abab`, giving `abaabb` and `ababab`.
- `|x| = 2`, `|y| = 2`. The only length-2 string is `ab`, giving `a (ab) b (ab) = aabbab`.
- `|x| = 4`, `|y| = 0`. This gives `a aabb b = aaabbb` and `a abab b = aababb`.

The five strings are `aaabbb`, `aababb`, `aabbab`, `abaabb`, and `ababab`. No other split has total length 6, and each balanced string has only one first-return decomposition, so none of these five is counted twice.

### Q20

Answer: A, C, D

(A) is true because `L` is defined by a context-free grammar.

(B) is false. The strings `a^n` are pairwise distinguishable: `a^i b^i` is in `L`, while `a^j b^i` is not when `j ≠ i`, because that string either violates the prefix count or does not have equal totals. A regular language has only finitely many distinguishable strings.

(C) is true by the inductive argument in Q10: `ε` is balanced, and `a x b y` is balanced when `x` and `y` are.

(D) is true: `S ⇒ aSbS ⇒ abS ⇒ ab aSbS ⇒ abab`, using `ε` for each inner `S`.
